# Agency Simulator

Game simulasi mengelola agensi kreatif/iklan, bisa dimainkan langsung di browser HP maupun laptop. Mulai dari studio kecil, menangkan tender, buka cabang, sampai jadi agensi terbesar di Indonesia dan dunia.

Run a creative agency, win tenders, open branches, and grow into the biggest agency from Indonesia to the world. Playable in any browser, in Indonesian and English.

## Main di sini / Play

https://anasyamhrdn.github.io/agency-simulator/

## Fitur / Features

- Pilih nama agensimu sendiri dan 4 tingkat kesulitan (Santai, Normal, Sulit, Direktur)
- Pilih tim dari staf dengan skill Kreativitas, Strategi, dan Klien
- Rekrut freelancer atau karyawan tetap, beri cuti saat kelelahan, atau berhentikan staf
- Tender dan pitching melawan agensi saingan
- Buka dan upgrade anak cabang di Bandung, Surabaya, Bali, Medan, Singapura, Tokyo, London, dan New York
- Naik level dari Startup sampai Global, dengan peringkat Indonesia dan dunia
- Dua bahasa: Indonesia dan English
- Simpan otomatis dan 3 slot save game

## Cara menang / How to win

Capai reputasi 300 dan miliki minimal 4 cabang. Kalau kas habis, agensimu bangkrut.

## Pasang di layar utama HP

1. Buka link game di Safari (iPhone) atau Chrome (Android).
2. iPhone: ketuk Bagikan, lalu Tambah ke Layar Utama. Android: menu titik tiga, lalu Tambahkan ke layar utama.

## Jalankan di komputer

Unduh `index.html` lalu buka di browser. Tidak perlu instalasi apa pun.

## Catatan

Progres game tersimpan di browser (localStorage), jadi hanya ada di perangkat dan alamat web yang kamu pakai untuk bermain.
